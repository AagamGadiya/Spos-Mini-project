Concurrent User Simulation

OS Concept Demo

Simulate multiple users submitting print jobs concurrently. This demonstrates thread synchronization, mutual exclusion, and the producer-consumer pattern in action.

10

Simulation Concept Explanation

Producer Threads

Each simulated user runs as a separate Java thread (producer) that submits print jobs concurrently to the shared spooler.

Consumer Thread

The printer worker is the consumer thread that processes jobs from the queue one at a time, ensuring mutual exclusion.

Shared Queue

The print queue is a shared data structure protected by a ReentrantLock. All access requires lock acquisition first.

Condition Variable

When the queue is empty, the consumer calls await(). When a producer adds a job, it calls signal() to wake the consumer.

About This Project

Printer Spooler System - SPOS Mini Project

This project demonstrates Operating System concepts through a web-based Printer Spooler System. Multiple users/processes submit print jobs to a shared printer, and the system manages scheduling, synchronization, and resource allocation.

SPOS Concepts Demonstrated

Process Synchronization Mutual Exclusion Critical Section Producer-Consumer FIFO Scheduling Thread Safety Race Condition Prevention Shared Resource Management Condition Variables ReentrantLock

Technology Stack

Backend: Java (built-in HttpServer, ReentrantLock, Condition, ExecutorService)
Frontend: HTML5 + CSS3 + Vanilla JavaScript
Communication: REST API with JSON
Data Storage: In-memory Java collections
